# Errores frecuentes en el ejercicio de trafico

**Tema:** Sesión 12 — Análisis de registros de tráfico con Python  
**Nivel:** basico

Una variable acciones debe inicializarse como acciones = Counter(); no confundirse con actions. No sumar fila["bytes"] sin int porque es texto. La guía tiene una pequeña inconsistencia de nombre de variable en un fragmento, pero sesion12_analizar_trafico.py utiliza correctamente acciones. Ejecutar desde la carpeta que contiene trafico.csv para evitar FileNotFoundError.
