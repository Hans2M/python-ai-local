# Codificacion del archivo y encabezados exactos

**Tema:** Sesión 12 — Análisis de registros de tráfico con Python  
**Nivel:** basico

El script proporcionado usa encoding="utf-8-sig" para aceptar CSV UTF-8 con o sin marca BOM; mantiene newline="". DictReader necesita los encabezados bytes, accion y origen escritos exactamente así (en minúsculas). Para contar servicio necesita servicio. No adivines encabezados distintos del archivo de clase.
