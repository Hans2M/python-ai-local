# Columnas y significado de trafico.csv

**Tema:** Sesión 12 — Análisis de registros de tráfico con Python  
**Nivel:** basico

El archivo de clase contiene fecha, hora, origen, destino, servicio, accion y bytes. Para el resumen obligatorio se leen las claves exactas fila["bytes"], fila["accion"] y fila["origen"]. Para agrupar por servicio en el reto, utilizar fila["servicio"]. Debe ser un CSV con encabezados; los datos son ficticios.
