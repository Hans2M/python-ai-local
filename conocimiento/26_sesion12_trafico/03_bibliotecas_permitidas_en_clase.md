# Bibliotecas permitidas en clase

**Tema:** Sesión 12 — Análisis de registros de tráfico con Python  
**Nivel:** basico

Utiliza exclusivamente la biblioteca estándar csv y collections.Counter; csv.DictReader permite acceder a las celdas por encabezado, Counter suma las apariciones, int convierte los bytes de texto a enteros, y for procesa las filas. La clase no emplea pandas, requests, scapy, pyshark ni un sistema externo.
