# Intersección de conjuntos

**Tema:** Diccionarios, tuplas, conjuntos y colecciones  
**Nivel:** basico

Obtener elementos en común entre dos conjuntos y eliminar duplicados.

## Ejemplo en Python

```python
a = {1, 2, 3, 5}
b = {3, 4, 5, 6}
print("Comunes:", sorted(a & b))
print("Únicos:", sorted(a | b))
```
