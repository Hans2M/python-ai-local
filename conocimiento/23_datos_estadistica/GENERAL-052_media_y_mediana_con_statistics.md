# Media y mediana con statistics

**Tema:** Procesamiento de datos y estadística descriptiva  
**Nivel:** basico

Calcular promedio y mediana usando la biblioteca estándar para listas numéricas no vacías.

## Ejemplo en Python

```python
from statistics import mean, median
notas = [11, 13, 16, 17, 18]
print("Promedio:", mean(notas))
print("Mediana:", median(notas))
```
