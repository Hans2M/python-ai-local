# Sumatoria usando while

**Tema:** Bucles for/while, listas, rangos y comprensiones  
**Nivel:** basico

Suma los números enteros positivos de 1 a n mediante contador while.

## Ejemplo en Python

```python
n = int(input("Ingrese n: "))
suma = 0
i = 1
while i <= n:
    suma += i
    i += 1
print("Suma:", suma)
```
