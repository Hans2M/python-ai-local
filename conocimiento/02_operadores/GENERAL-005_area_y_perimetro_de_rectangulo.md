# Área y perímetro de rectángulo

**Tema:** Operadores aritméticos, lógicos y comparaciones  
**Nivel:** basico

Usar multiplicación, suma, variables float y f-strings para calcular área y perímetro.

## Ejemplo en Python

```python
ancho = float(input("Ancho: "))
alto = float(input("Alto: "))
area = ancho * alto
perimetro = 2 * (ancho + alto)
print(f"Área: {area:.2f}; Perímetro: {perimetro:.2f}")
```
